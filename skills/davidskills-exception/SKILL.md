# DavidSkills: Exception / Inquiry

Use for **lightweight** work: locate files, explain code, quick research, clarify a bug report—**without** entering full SkillDocs planning or implementation.

When the next action becomes planning, coding, review, or measured debugging, **reroute** immediately.

## Load order

1. Read only the minimum files needed to answer
2. Use web lookup only for latest-external / verification-style requests
3. Do not load Planning / Development / Review / Performance workflows unless rerouting

## Required behavior

- Do not create or rewrite SkillDocs artifacts unless the user clearly moves into Planning/Development or explicitly asks to persist notes in the doc system.
- Prefer direct inspection over loading unrelated skills.
