# Skill Evolution (Update route)

Use when capturing **shared** rules that should persist for this DavidSkills install.

## Capture filter

Persist only when the user states an explicit, reusable rule (style, performance standard, allowed/forbidden tooling). Skip one-off venting or chatty preferences.

## Placement

- **Shared / install-wide:** append to `skills/davidskills/protocols/custom-<topic>.md` (create when needed). Keep files focused; prefer a new `custom-*.md` over an unbounded junk drawer.
- **Project/domain-specific:** do not force into DavidSkills shared protocols; prefer the project’s own docs or a dedicated project skill.

## After writeback

Report path and summary; stop — do not continue into implementation unless the user reroutes.
