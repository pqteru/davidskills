# SkillDocs templates (DavidSkills)

DavidSkills uses these **bounded artifacts** under the active feature folder.

| File | Role |
|------|------|
| `architecture.md` | Boundaries, flows, approved shape |
| `design.md` | Implementation contract for the active stack |
| `test.md` | Test plan / suites / ownership |
| `task.md` | Active phase tasks only |
| `verification.md` | Commands, outputs, evidence |

Copy from these stubs when bootstrapping a new feature. Keep each file **under 600 lines**.

Record stack-specific dependency and test commands in `design.md` / `test.md` (use repo-native package managers and scripts).
